# Функциональные требования

Система должна обеспечить следующий функционал:

- публикация постов, которые содержат в себе: фотографии, комментарии, геопозицию
- возможность поставить лайк на пост и комментарий
- у каждого путешественника есть страница - где публикуются посты, на каждого путешественника можно подписаться, соответственно у путешественников будут подписчики (возможность получить список подписчиков)
- поиск мест по названию (с фильтрацией по популярности) - при вводе места выходит лента постов с этого места
- общая лента, которая состоит из постов подписок, а также лента отдельного пользователя (посты должны идти от самых новых к самым старым)
